**#🌸 SkinMatch AI**
Sistem Rekomendasi Skincare Berbasis NLP & Semantic Similarity
SkinMatch AI adalah sistem rekomendasi skincare berbasis AI yang menggunakan NLP (Natural Language Processing) dan Semantic Similarity untuk merekomendasikan produk skincare sesuai kebutuhan kulit pengguna.

**#✨ Fitur**
Rekomendasi skincare berbasis semantic similarity
Fine-tuned Sentence Transformer
Intent detection (cleanser, serum, sunscreen, dll)
Hybrid scoring
OOD detection (menolak input tidak relevan)
Dynamic recommendation reasoning
