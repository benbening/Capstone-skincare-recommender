<h1 align="center">🌸 SkinMatch </h1>

<p align="center">
Sistem Rekomendasi Skincare Berbasis NLP & Semantic Similarity
</p>

---

SkinMatch AI adalah sistem rekomendasi skincare berbasis AI yang menggunakan NLP (Natural Language Processing) dan Semantic Similarity untuk merekomendasikan produk skincare sesuai kebutuhan kulit pengguna.

## ✨ Fitur

1. Rekomendasi skincare berbasis semantic similarity  
2. Fine-tuned Sentence Transformer  
3. Intent detection (cleanser, serum, sunscreen, dll)  
4. Hybrid scoring  
5. OOD detection (menolak input tidak relevan)  
6. Dynamic recommendation reasoning
